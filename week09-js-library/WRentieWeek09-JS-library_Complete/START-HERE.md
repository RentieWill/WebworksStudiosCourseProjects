# Start Here — Week 9

## Your Job

This page is already designed, responsive, and populated with client content.

Your task is **not to redesign the site**.

Your task is to convert the supplied static project-card collection into a responsive
carousel using the assigned **Splide** JavaScript library.

## Before You Code

Read these official Splide documentation sections:

- Getting Started: https://splidejs.com/guides/getting-started/
- Structure: https://splidejs.com/guides/structure/
- Options: https://splidejs.com/guides/options/
- Accessibility: https://splidejs.com/guides/accessibility/

Then begin the Library Evaluation section in `README.md`.

## Setup

1. Place this entire `week09-js-library` folder inside your existing public `webworks-studio` repository.
2. Open the entire Week 9 folder in Visual Studio Code.
3. Preview `index.html` before making changes.
4. Open the browser console.
5. Confirm you see:

```text
Week 9 project script connected.
```

6. Follow the TODO markers in `index.html`, `css/styles.css`, and `js/script.js`.
7. Use the exact Splide version and CDN references supplied by your instructor/Canvas assignment.
8. Test before changing additional options.
9. Complete `README.md`.
10. Commit and push.
11. Test the GitHub Pages version.
12. Submit the direct Week 9 GitHub folder link in Canvas.

## Starter State

The six project cards are intentionally displayed as a normal responsive CSS grid.

That gives you working semantic content before JavaScript is added.

During the assignment, you will apply Splide's required component structure to this
content and configure the library.

## Scope

Required:
- one Splide carousel;
- responsive configuration;
- arrows;
- pagination;
- accessible labeling;
- keyboard testing;
- dependency documentation.

Not required:
- autoplay;
- a second library;
- npm;
- React;
- custom carousel code;
- advanced animation.

Refer to the Canvas Week 9 assignment for complete requirements.
